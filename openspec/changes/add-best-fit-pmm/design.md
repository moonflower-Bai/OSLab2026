# Design

## Context

结构参考 `kern/mm/default_pmm.c` 的 First-Fit 实现。框架提供的 `best_fit_check()` 直接引用 `free_list` 和 `nr_free`，因此它们必须在测试函数之前定义；注册结构要引用 `best_fit_check`，必须写在测试函数之后。

## Goals / Non-Goals

**Goals:**
- 在不改动测试函数和公开接口的前提下满足 spec 中的分配、释放语义。

**Non-Goals:**
- 不优化查找复杂度（如按大小分桶或平衡树），沿用单链表线性扫描。

## Decisions

1. **空闲链表按地址有序**，与 First-Fit 相同。这样合并只需检查链表中的前驱和后继。抽出一个按地址插入的辅助函数，供初始化和释放共用。
2. **分配时完整扫描链表取最小足够块，遇到大小恰为 n 的块提前结束**。恰好匹配不可能被更小的块超越，提前结束不改变结果。备选方案是维护按大小排序的第二个链表，但实验规模下没有必要，且会增加合并的维护成本。
3. **切分时剩余部分插回原块所在位置**（记录被删除块的前驱后在其后插入），保持地址顺序，不需要重新扫描。
4. **注册结构放在文件末尾**，因为 `.check = best_fit_check` 需要测试函数已声明。

## Risks / Trade-offs

- [每次分配 O(n) 扫描] → 实验页数有限，可接受。
- [内核尚不能编译：练习 1 的 `page_init()` 未实现] → 用主机端模拟头文件编译真实的 `best_fit_pmm.c` 并运行原有 `best_fit_check()` 先行验证；QEMU 验收待 `page_init()` 完成后补做。
