# Spec Delta

## Purpose

为 Lab4 的虚拟内存页操作和线程内核栈提供物理页管理基础。复用 Lab2 已完成的内存探测和 Best-Fit 分配行为，使后续模块能通过既有接口申请、释放和统计物理页。

## ADDED Requirements

### Requirement: 初始化 Lab4 物理页管理

Lab4 MUST 根据设备树提供的内存范围初始化物理页描述符，并将固件、内核和页描述符占用范围之外的可用页登记为可分配内存。

#### Scenario: 默认 QEMU 内存启动
- **WHEN** Lab4 在支持的 QEMU 内存布局下完成设备树解析并初始化物理内存
- **THEN** 页描述符覆盖可管理物理内存，初始空闲页范围按页对齐且避开固件、内核和描述符

#### Scenario: 启用分页后进入内核
- **WHEN** QEMU 从物理加载地址进入 Lab4 并启用 Sv39 分页
- **THEN** 内核 MUST 继续取指并跳到高地址，进入 C 初始化前 MUST 清除启动期低地址恒等映射

### Requirement: 使用 Lab2 Best-Fit 分配和回收

Lab4 MUST 从能满足请求的最小空闲块分配连续页，回收时合并相邻空闲块，并维护空闲页数。

#### Scenario: 不同大小的空闲块可供选择
- **WHEN** 调用者请求连续物理页且存在多个足够大的空闲块
- **THEN** 分配器使用最小的合适块，扣除分配页数，保留剩余空闲页

#### Scenario: 归还相邻的物理页
- **WHEN** 调用者释放与既有空闲块相邻的页
- **THEN** 相邻空闲块合并，空闲页总数增加本次归还的页数
