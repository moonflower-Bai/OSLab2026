# Lab4 虚拟内存页操作测试

## Purpose

在 Lab4 功能模块一实现前提供独立、可重复的测试入口，分别验证页表状态、物理页回收、真实访存和软件模型中的翻译缓存行为，并区分未运行和断言失败。

## ADDED Requirements

### Requirement: 单元测试验证映射及回收

宿主机单元测试 SHALL 调用实际的 `page_insert()` 和 `page_remove()`，验证叶项有效性、物理页、权限、引用计数和回收情况。

#### Scenario: 映射、换页与权限修改

- **WHEN** 首次插入页、插入同页别名、原址原页更新权限或原址换页
- **THEN** 对应叶项、物理页引用数和回收事件 MUST 符合操作语义，原址原页更新期间不得释放数据页

#### Scenario: 删除映射及空地址

- **WHEN** 删除共享映射、最后一条映射、已删除的映射、没有完整路径的地址或路径存在但叶项无效的地址
- **THEN** 测试 MUST 检查共享页不会被提前回收、最后一条映射删除时只回收一次、无映射的删除不尝试分配页且不改变空闲页数或既有映射

#### Scenario: 中间页表分配失败后可重试

- **WHEN** 对空根页表分别注入第一次和第二次中间页表分配失败
- **THEN** 测试 MUST 检查返回 `-E_NO_MEM`、目标不出现有效叶项、已有映射和目标数据页的引用均不变、解除故障后可重试，并单独核对与清理可能留存的中间表页

### Requirement: QEMU 真实访存验证翻译和异常

QEMU 测试 SHALL 用独立启动入口和链接配置启动实际 RV64 代码，使用合法的 Sv39 页表路径与权限，并输出机器可识别的逐项结果和结束标识。

#### Scenario: 换页后的首次读取

- **WHEN** 同一虚拟地址先从 A 读出标记，再换为不同标记的 B
- **THEN** 下一次读取 MUST 立即返回 B，A 的旧别名仍返回 A，测试代码不得在换页与读取之间主动失效 TLB

#### Scenario: 降权与撤销后的精确异常

- **WHEN** 测试先经可写映射写入，降为只读并尝试写入，再删掉映射并尝试读取
- **THEN** 降权后读取 MUST 保持成功、写入 MUST 产生对应地址的 store page fault 且数据不变、删除后读取 MUST 产生对应地址的 load page fault，异常处理 MUST 核对 `scause` 和故障地址并继续执行测试

### Requirement: 独立模型与确定性翻译缓存验证

模型测试 SHALL 独立维护按 `(页表, 虚拟页号)` 索引的物理页和权限，不用被测函数预测映射或引用数，并在每个操作后比较实际叶项、数据页引用及缓存翻译。

#### Scenario: 按种子运行操作序列

- **WHEN** 运行模型层
- **THEN** 至少四个固定种子 MUST 各执行至少 256 步，覆盖映射、换页、权限更新、删除和查询，以及同页别名、两张表的同一虚拟地址、2 MiB 与 1 GiB 边界两侧的 4 KiB 页；失败 MUST 输出种子、步号和可重放的序列

#### Scenario: 缓存翻译尚未收到适用的失效操作

- **WHEN** 有效缓存对应的映射被换页、降权或撤销，但实际实现没有发出适用的失效操作
- **THEN** 模型内的旧翻译 MUST 保持有效，测试 MUST 因翻译不匹配而报错

### Requirement: 独立运行入口和真实结果

从仓库根目录执行 `bash lab4/test/run_vmem_tests.sh` SHALL 依次尝试单元、QEMU、模型三层，只在三层全部实际执行且通过时返回 0。测试与构建临时文件 SHALL 限定在 `lab4/test/` 内，且不得直接或间接读取 `lab4/tools/`。

#### Scenario: 某层失败或不可运行

- **WHEN** 工具缺失、编译或链接失败、接口尚无定义、断言失败或 QEMU 超时
- **THEN** 脚本 MUST 输出逐项的「通过」「错误」或「未运行」和实际失败原因，继续尝试其他层，最后汇总三层状态并返回非零

#### Scenario: 校验测试灵敏度

- **WHEN** 在测试临时副本中分别引入原址原页引用多增、末次删除漏回收、换页遗漏 TLB 失效
- **THEN** 每个变体 MUST 至少被对应的已运行断言检出；默认入口不得链接用于校验的临时实现
