# Spec Delta

## Purpose

为 Lab4 定义虚拟地址与数据页之间的建立、更新和撤销语义，使页表项、物理页引用计数和本地地址翻译一致，同时明确页表分配失败时应保留的状态。

## ADDED Requirements

### Requirement: 建立或更新末级映射

`page_insert()` SHALL 在成功时返回 `0`，并将末级项设置为目标物理页号、本次传入的权限和 `PTE_V`。

#### Scenario: 首次映射或添加别名
- **WHEN** 目标地址原无有效映射且能取得末级项
- **THEN** 该地址映射到目标数据页，目标页的引用增加一次，其他地址的映射保持不变

#### Scenario: 同页更新权限
- **WHEN** 目标地址已映射到同一物理页
- **THEN** 末级项使用本次传入的权限，不沿用旧权限，数据页保持已分配且引用不变

#### Scenario: 替换为另一物理页
- **WHEN** 目标地址已映射到不同物理页
- **THEN** 新页引用增加一次，旧页引用减少一次，且只有旧页引用降至零才回收旧页

### Requirement: 页表分配失败不提交数据页映射

无法取得末级项时，`page_insert()` SHALL 返回 `-E_NO_MEM`，不得留下有效的新叶项、改变已有映射或改动目标数据页的引用计数。已经挂接的空中间表可以保留供重试。

#### Scenario: 任一级中间表分配失败
- **WHEN** 首级或次级中间表分配失败
- **THEN** 返回 `-E_NO_MEM`，原有叶项和目标数据页引用不变，目标地址仍没有有效映射，解除分配故障后可重试

### Requirement: 撤销末级映射

`page_remove()` SHALL 无分配地查找末级项。仅对有效映射清除叶项并减少一次旧页引用，引用降为零时回收旧数据页；操作不回收中间页表。

#### Scenario: 删除有效映射
- **WHEN** 目标地址存在有效映射
- **THEN** 清除末级项；旧页还有其他引用时保持已分配，最后一个引用被删除时交还分配器

#### Scenario: 删除不存在的映射
- **WHEN** 目标地址没有页表路径或其末级项无效
- **THEN** 不分配内存、不修改页表或引用计数，直接返回

### Requirement: 先同步翻译再回收数据页

建立、更新或撤销映射时，末级项写入 SHALL 先于对相应本地翻译的失效；失效完成 SHALL 先于旧数据页被分配器重新使用。

#### Scenario: 处理器已缓存旧翻译
- **WHEN** 有效映射被替换、降权或撤销，且该地址的旧翻译仍被缓存
- **THEN** 操作返回后本地访存观察到新的映射或权限，不再使用旧翻译，回收旧页时该地址也已不能通过旧翻译访问该页
