# Design

## Context

Lab 4 的集成分支已有骨架，但章节状态仍为 lab3，页表、调度和部分先前实验功能尚未完成。

## Goals / Non-Goals

**Goals:** 依据现有接口创建内核线程，并在资源不足时清理已分配资源。

**Non-Goals:** 实现其他功能模块或真正的用户地址空间复制。

## Decisions

- 将 lab4 设为当前章节，保留 frozen 列表，以满足现有分支和修改范围规则。
- PCB 零初始化后设置未初始化状态、无效 PID 和内核页表；idleproc 复用启动栈，initproc 通过正常 fork 路径创建。
- 先分配 PCB、栈和现场，再在关中断的临界区检查容量、分配 PID 并挂入链表和哈希表，最后唤醒；失败时按逆序释放。容量检查也在临界区内，避免并发创建突破上限。
- 线程以保存的 s0/s1 传递函数与参数，恢复时经 forkret 和已有 trap 返回路径进入入口；copy_mm 在本实验保留空操作。

## Risks / Trade-offs

- [其他模块未完成] → 对本模块单独编译及测试，完整启动待各模块集成后验证。
- [地址空间复制缺失] → 本实验只支持内核线程，后续实验扩展 copy_mm。
